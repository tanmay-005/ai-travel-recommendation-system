# 🗺️ Yatra — AI Travel Recommendation System

A full-stack, location-aware travel recommendation platform for India.
Suggests tourist spots, restaurants, cafes, parks and more based on your
**location, preferences, and usage patterns** — with zero paid APIs.

---

## ✨ Features

| Feature | Details |
|---------|---------|
| **Nearby (Hybrid)** | Distance + avg rating weighted score (55 % / 45 %) |
| **Content-Based** | TF-IDF similarity across category + city + place name |
| **By City** | Browse all places in any of 80+ cities, filtered by category |
| **For User** | Collaborative: top unvisited places based on user rating history |
| **Live Search** | Global search bar with instant dropdown across all places |
| **Favourites** | Save/unsave places, persist in session, export to CSV |
| **CSV Export** | Export any result set or saved places as CSV |
| **Route** | Click any card → turn-by-turn route via OpenStreetMap routing |
| **Map** | Leaflet + OSM tiles, custom emoji markers per category |

## ⚙️ Setup

```bash
# 1. Clone & enter
git clone https://github.com/your-username/yatra.git
cd yatra

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Generate dataset (run ONCE — takes ~20 min, fetches from OSM)
python fetch_osm_places.py

# 5. Generate ratings (run ONCE — instant)
python rating.py

# 6. Start the app
python app.py
```

Open **http://127.0.0.1:5000** in your browser.

## 🧠 Recommendation Engine

### Hybrid Score (Nearby mode)
```
score = 0.55 × (1 - normalised_distance) + 0.45 × (avg_rating / 5)
```
Closer places win, but a highly-rated place 10 km away beats a mediocre one 2 km away.

### Content-Based (Similar mode)
TF-IDF vectorisation on `category + city + place_name` tokens, bi-gram range,
cosine similarity matrix. Finds places with matching character regardless of location.

### Collaborative (For Me mode)
Identifies places not yet visited by the user, ranks by community average rating.
Works best with real user data; synthetic ratings serve as a demo baseline.

## 🛠️ API Endpoints

| GET | `/api/categories` | Category list + icons |

| GET | `/api/nearby` | Hybrid nearby recommendations |
| GET | `/api/similar` | Content-based similar places |
| GET | `/api/for_user` | User-based recommendations |
